About Youth Justice NT

Youth Justice NT is a Django-based web application created to make youth diversion and support programs across the Northern Territory easier to find and understand. Instead of searching through different websites separately, users can access important program details in one place.

This project focuses on alternatives to detention by highlighting support services such as diversion, mentoring, throughcare, education, and community-based programs. The aim is to make these services more visible and accessible for users.

The system includes useful features such as searching, filtering by region and category, sorting, featured programs, availability status, and detailed program pages. These features help users browse programs more clearly and quickly.
