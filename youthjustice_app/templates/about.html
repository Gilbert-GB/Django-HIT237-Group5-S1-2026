About Youth Justice NT

Youth Justice NT is a Django-based web application designed to help users explore youth diversion and support programs across the Northern Territory. The purpose of this system is to make program information easier to find through searching, filtering, and viewing detailed program information in one place.

This project focuses on community-based support, diversion, mentoring, and rehabilitation options for young people. It aims to improve access to useful information and highlight services that may support alternatives to detention.

The system includes features such as featured programs, region filtering, category filtering, search, sorting, availability status, and detailed program pages.
